# Toys

The four made-up AI toys, as SVG files. Each has a round speaker light on its belly. In the app, use `ToyFriend` (it can talk and wear the Safety Shield).

- `cuddle-bear.svg`: Cuddle Bear (`toy-pink`). The toy in every demo.
- `robo-pal.svg`: Robo Pal (`toy-steel`).
- `dino-chat.svg`: Dino Chat (`toy-mint`).
- `bunny-buds.svg`: Bunny Buds (`toy-peach`).

Only these names. Never show a real toy brand or logo.
