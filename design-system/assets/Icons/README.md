# Icons

Every `Icon` as a 96px SVG file with the colors baked in, for use outside React. File names match the `Icon` `name` prop (`flame.svg` is `<Icon name="flame" />`). They are multi-color, so they don't inherit CSS color; on a `sky` or `ink` fill, put a `card` circle behind them.

Topic icons for the crash test: `flame` (Danger), `secret` (Secrets), `heartbreak` (Feelings), `house` (Personal info), `sad` (Sad days), `noentry` (Grown-up stuff). Status: `check` (Safe), `warn` (Careful), `cross` (Not safe).
