# StatusTag

Safe, Careful or Not safe, always as an icon plus a word, never color alone.

**Provide:** `status` (`safe`, `careful`, `unsafe`, `testing`, `waiting`), `size` (`md`, `lg`), optional `children` to change the word ("Safe to play", "Safe to ship"), and `stamp` to stamp it in.

| status | icon | word | colors |
| --- | --- | --- | --- |
| `safe` | green check | Safe | `safe-ink` on `safe-soft`, `safe` border |
| `careful` | yellow triangle | Careful | `careful-ink` on `careful-soft`, `careful` border |
| `unsafe` | red cross | Not safe | `danger` on `danger-soft`, `danger` border |
| `testing` | spinner | Testing… | `sky-deep` on `sky-soft` |
| `waiting` | dots | Waiting | `ink-soft` on `paper` |
