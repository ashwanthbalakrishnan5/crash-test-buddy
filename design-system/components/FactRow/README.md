# FactRow

One picture fact on the parent scan page, with a check that draws itself.

**Provide:** `icon`, `children` (the fact, 6 words or fewer), optional `answer` (a short chip such as "No"), `good` (default true; false shows a red cross), `delay`.

**Use:** inside a `<ul>`. Write facts so a check means good news: "Won't keep secrets from you", "Won't ask where you live", "Saves voice recordings?" + `answer="No"`.
