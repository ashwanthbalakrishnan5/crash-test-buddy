# BigButton

The chunky toy button. One `primary` per screen: the thing a 5-year-old should press.

**Provide:** `children` (2–4 words), `variant` (`primary`, `secondary`, `quiet`), `size` (`lg` 76px tall, `md` 56px), `icon` and/or `iconRight` (an Icon name), `pulse` to draw the eye once the next step is ready, and the usual button props.

**Use:**
- Start the label with a verb: "Scan a toy", "Add Safety Shield", "See report card".
- `secondary` for Back and Report a problem; `quiet` for a skip or a second way in ("Watch the demo").
- It lifts on hover, sinks onto its edge when pressed, and ripples where you touch.
