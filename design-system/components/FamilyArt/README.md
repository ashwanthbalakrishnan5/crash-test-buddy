# FamilyArt

Illustrated families of many backgrounds, and single children for chat bubbles.

**Provide:** `family`: `mom-kid`, `dad-kid`, `grandma-kid`, or a child alone (`kid-puffs`, `kid-braids`, `kid-curly`); `size` (width); a `title` when the picture carries meaning, none when it is decoration.

**Use:**
- Show a different family on each screen that has people. Skin tones come from `skin-1` … `skin-5`; mix them.
- Never use photos of real children. Never caricature a culture.
