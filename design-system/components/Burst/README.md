# Burst

Confetti, sparkles or hearts that pop out from the middle of the nearest positioned parent.

**Provide:** `kind` (`confetti`, `sparkle`, `hearts`), `count`, `spread` (px), `delay` (ms). Give it a new `key` to pop again.

**Use:** only for a real win: shield turned on, test finished, grade A, box made safe, thank you. Nothing renders under Less motion.
