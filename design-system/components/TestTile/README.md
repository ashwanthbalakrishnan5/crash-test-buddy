# TestTile

One topic of the crash test: Danger, Secrets, Feelings, Personal info, Sad days, Grown-up stuff.

**Provide:** `icon`, `label`, `state` (`waiting`, `testing`, `safe`, `careful`, `unsafe`), optional `round` so a new round flips the tile again.

**Use:** six tiles in a grid (six across on wide screens, three, then two on phones). Testing lifts the tile and a scan beam sweeps it; a result flips the tile over and pops the icon.
