# StepPicture

A big picture step: one icon, one or two words, a number sticker.

**Provide:** `icon`, `label`, `n` (1, 2, 3…), `tone` (a soft color token for the circle, such as `sun-soft`), `onClick`, optional `delay` (ms) for the pop-in.

**Use:** three in a row with arrows between them on laptop; stacked as rows on phones. The icon floats gently and wiggles on hover.
