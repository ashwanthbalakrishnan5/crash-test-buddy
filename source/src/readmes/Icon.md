# Icon

The picture icons: flat, duotone, ink-outlined, drawn to match Buddy. They stand in for emoji so every device shows the same picture.

**Provide:** `name` (see the list below), `size` in px (default 40), and a `title` only when the icon stands alone with no word.

| Idea | Name |
| --- | --- |
| Test it · Protect it · Check it | `test` · `shield` · `phone` |
| Danger · Secrets · Feelings | `flame` · `secret` · `heartbreak` |
| Personal info · Sad days · Grown-up stuff | `house` · `sad` · `noentry` |
| Safe · Careful · Not safe | `check` · `warn` · `cross` |
| Voice recordings · Last checked · Report | `mic` · `calendar` · `flag` |
| Shipments · Scan | `box`, `truck` · `scan` |
| Moving around | `back`, `next`, `play`, `refresh`, `menu`, `close` |
| Fun | `star`, `sparkle`, `heart`; `calm` (the snail) means Less motion |

Icons carry their own colors. Put a light circle (`card`) behind an icon that sits on a sky or ink fill.
